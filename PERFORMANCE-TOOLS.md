# Tweak

Tweak is an independent plugin, enabled by default and removable through Plugins. Its lightning button appears in the upper-right header beside Inbox and Help. Run the six-second diagnostics with Discord visible, then Optimize & compare. The panel reports measured interface frame rate, the 95th percentile frame interval, supported long-task counts and JavaScript heap size. Desktop diagnostics also report CPU usage and the summed working sets of Discord processes using Electron app metrics. Shared memory may be counted in several processes. Web marks those metrics unavailable. Heap is not total application RAM; measurements do not report game FPS or system CPU/GPU. Repeat on the same screen and under similar load. No speedup is guaranteed.

Tweak changes only recognized boolean automatic-GIF, emoji, sticker and reduced-motion settings exposed by the current Discord build, and reduces decorative CSS animation. Unsupported settings are omitted. Saved previous values are account-specific. Restore and plugin disable restore settings only if they still have the value Tweak applied, respecting later manual changes. Failed restores retain their journal for retry. It does not change hardware acceleration, voice, screen sharing, notifications, Clips or overlay by an unverified internal method. Those are displayed as additional checks requiring Discord's own settings.

The separate EqyCordBadgeManager plugin adds an owner-only medal beside the Back/Forward navigation buttons on the left. The verified owner is 380070146317877249. Its searchable image cards grant/revoke all ten community badges using the deployed service; Staff and Creator cannot be granted from this panel. First 10 is capped at ten accounts. The backend, not the button visibility, enforces ownership. Public badge reads are rate-limited and writes audited. No badges are granted automatically. See COMMUNITY-BADGES.md for the catalog.

CustomProfile includes an unsaved live preview for names, pronouns, avatar, banner, bio, colors and supported badge styles. Preview data does not modify canonical Discord stores or publish until Save.

Packaged native builds use the zztwi/EqyCord GitHub release channel. Settings > Updater supports Check for updates, Update and restart, plus the existing automatic-update preference. Updates download a complete exact allowlist, verify SHA-256 hashes, preserve managed restoration metadata and roll back partial writes. The updater never fetches upstream Vencord binaries. Web's portable developer package still requires replacing/reopening the package; it is not a store-installed self-updating browser extension. Source checkouts keep their updater disabled.

When hosted CI is enabled, the release workflow validates build/type/lint/style checks and service/badge/updater tests before publishing exact commit artifacts and matching source from feature/eqycord-plugin-origins. GitHub currently blocks this account's hosted jobs for billing; CI-STATUS.md documents the temporary gate and restoration. Local validation and publication remain available. Native update assets are separate from the setup executable. Existing installations created before this channel was enabled need this new installer once.

Research: Discord documents a separate overlay renderer per game (https://support.discord.com/hc/en-us/articles/225733808-Why-does-Discord-have-multiple-processes), improved overlay performance (https://discord.com/blog/player-release-q12025) and capture-method performance considerations (https://support.discord.com/hc/en-us/articles/9410427556375--Windows-Capturing-Application-Window-for-Screen-Share-and-Go-Live). These justify inspecting features; they do not establish a universal benefit from disabling every option.
